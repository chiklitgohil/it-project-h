Project Title: Hospital Management System
Group ID: 30
Language: C

To Compile:
gcc main.c auth.c data.c appointment.c report.c analytics.c -o HMS.exe

To Run:
.\hms.exe  (Windows)
./hms    (Linux)

Ensure all .dat files are in the same directory. Ensure "data" dir exist in the project dir.
The program starts with a login screen. Use credentials in users.dat or doctors.dat to access role-specific menus.
